SKYWARD RINGS is an original 2.5D flight game that runs in a desktop browser from static files. Throttle up, take off from the runway, climb through a course of glowing target rings over coastline, river and patchwork fields, then fly the final approach and land inside the touchdown zone - scored by rings hit, landing smoothness and time, with lit instruments and a full HUD (altitude, speed, heading) in frame throughout.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
